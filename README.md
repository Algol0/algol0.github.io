# Portfolio zodiak (Astro + GitHub Pages)

1. Copia el contenido de esta carpeta sobre tu repo (sobrescribe `src/`, `public/`, `astro.config.mjs` y `.github/`).
2. Instala la fuente: `npm install @fontsource-variable/jetbrains-mono`
3. Prueba en local: `npm run dev`
4. Settings > Pages > Source: GitHub Actions. Haz push a `main`.

Pendiente de personalizar:
- Correo en `src/layouts/Base.astro`
- `public/cv.pdf` (tu CV en PDF)
- Textos de la portada (`src/pages/index.astro`) y del CV (`src/pages/cv.astro`)
